# Qué entregar en EVA

La instrucción mostrada en la actividad de EVA solicita adjuntar el enlace del repositorio de GitHub donde está alojado el proyecto. La entrega es individual, aunque el trabajo se haya realizado en equipo.

## Enlace previsto del repositorio

https://github.com/jeancarlosperezpacheco2000-png/Proyecto-SIVIGILA-2018-Salud-Publica

Este enlace quedará disponible cuando se cree el repositorio con ese nombre y se ejecute correctamente `git push`.

## Pasos en EVA

1. Abre la actividad **Entrega Final del Proyecto – Consumo de API, Python, SQL Server y arquitectura MVC**.
2. Pulsa **Agregar entrega**.
3. En el campo de texto de la entrega, pega el enlace del repositorio público de GitHub indicado arriba.
4. Guarda los cambios y pulsa el botón final de envío/confirmación que muestre EVA.
5. Verifica que EVA indique que la entrega quedó enviada. La captura de EVA debe mostrar el estado de envío.

Según la instrucción de la actividad, el elemento principal a registrar en EVA es el enlace del repositorio. No sustituyas ese enlace por el ZIP.

## Antes de enviar

Comprueba que el repositorio público contenga:

- Código fuente y estructura MVC.
- Script SQL `sql/crear_base_datos.sql`.
- `requirements.txt` y `README.md`.
- Presentación `presentation/Presentacion_SIVIGILA_2018.pptx`.
- Evidencias reales dentro de `evidencias/`, generadas después de ejecutar la aplicación.

No se incluyen capturas simuladas. El estudiante debe guardar las capturas reales de la API, SQL Server, sincronización, página principal, filtro y prevención de duplicados en su computador y agregarlas a `evidencias/` antes de hacer el último `git add .`, `git commit` y `git push`.
